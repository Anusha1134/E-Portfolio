02 / FOUNDATION

CRYPTOGRAPHY CONCEPTS

The building blocks behind secure communication.

01

Plaintext

Original readable information before encryption is applied.

02

Ciphertext

Scrambled information produced after encryption.

03

Encryption

Converting plaintext into ciphertext using an algorithm and key.

04

Decryption

Recovering the original plaintext from ciphertext using the correct key.

05

Symmetric Key

The same secret key is used for encryption and decryption.

06

Asymmetric Key

A public/private key pair enables secure communication without sharing one secret key.

07

Hashing

One-way transformation used for integrity, authentication and password protection.

08

Digital Signature

Provides authenticity, integrity and non-repudiation for digital data.

caesar_cipher.py
def caesar(text, shift):
    result = ""

    for ch in text:
        if ch.isalpha():
            base = ord('A') if ch.isupper() else ord('a')
            result += chr((ord(ch)-base+shift)%26+base)
        else:
            result += ch

    return result

print(caesar("HELLO", 3))

Learning Cryptography & Network Security helped me understand how information can be protected against unauthorized access and manipulation. I explored classical ciphers such as Caesar and Playfair and then studied modern techniques including DES, AES, RSA and Diffie–Hellman.

The practical exercises helped me connect theoretical concepts with programming. I learned that strong security depends not only on algorithms but also on key management, authentication, integrity and secure implementation.
