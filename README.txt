# Cryptography & Network Security E-Portfolio

## Files
- index.html — complete portfolio website
- style.css — animations, responsive design and cybersecurity theme
- script.js — navigation, Matrix background, scroll animations and Caesar Cipher playground

## How to run
1. Extract the folder.
2. Open it in VS Code.
3. Double-click `index.html`, or use the Live Server extension.
4. Replace placeholders such as:
   - YOUR REGISTER NUMBER
   - your email
   - LinkedIn link
   - YOUR PHOTO
5. Replace the sample practical/project content with your own screenshots and programs.

## Suggested additions
Create an `assets` folder and add:
- profile.jpg
- certificate images
- program screenshots
- mini-project screenshots
- algorithm diagrams

Then update the image areas in `index.html`.

## Google Sites
If you specifically need a Google Sites submission, this website can be used as the design/content reference. Google Sites does not directly import a complete HTML website as an editable site; you can recreate the sections in Google Sites or publish this HTML website separately if your faculty accepts a normal web link.
